# Keycloak FactuCore

El despliegue crea el realm de aplicación `factucore`.

El realm de aplicación es independiente del `master` de Keycloak.

La cuenta `admin` del realm `factucore` es la cuenta administrativa inicial de FactuCore. Las demás cuentas deben ser creadas posteriormente desde la interfaz administrativa de FactuCore.

El usuario administrador de `master` se utiliza únicamente para administrar Keycloak, no como usuario de negocio de FactuCore.
